Help with ShortformBeGone.

Write to us, or open an issue where everyone can see the answer. Both reach the people who built it.

01 — Where to ask

One address and one issue tracker.

Email apps@agentsee.work Open an issue on GitHub

Email for anything private. An issue for a bug, a site that slips through, or an app that should be on the list.

It helps to say which device and iOS version you have, whether the device is supervised, and what the app's Status tab shows for each layer. For something that should have been blocked, the address is enough; the Rules tab has a box that tests any address against the rules.

02 — Asked first

The short answers.

Shorts or Reels still load in Safari

Check Settings → Apps → Safari → Extensions: ShortformBeGone and ShortformBeGone Guard should both be on, and the Guard set to Allow for youtube.com, instagram.com, facebook.com and snapchat.com. They may not run in Private Browsing.

The Status tab says the network filter is not set up

That is expected until the device is supervised and the locked profile is installed. The Safari blocker works without it. What the lock takes is on the ShortformBeGone page.

Where are the profile files?

On the ShortformBeGone page, with the steps for using them. Open it on your Mac.

I have lost the removal password

We cannot recover it. The script makes the password on your Mac and nothing is sent to us. A full restore of the device from a computer removes the profile and everything else, which is the way out that always exists.

I want to change the rules

Your keyholder enters the removal password, you remove the profile, edit the template, and install it again with a new password.

The setup guide and the known gaps are in full in the README. The app collects no data; see the privacy policy.
