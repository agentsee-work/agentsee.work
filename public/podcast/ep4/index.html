When code is the cheap part

Abrar takes James through what his job is now that producing the code is the cheap part. Coding was always the mechanism and engineering the problem-solving, so the work has moved to the spec, to deciding what should be built at all (one more export button, or a multi-select that carries the next request too), and to learning a domain the agent does not know. He describes the review agent he hands his own understanding of a feature to, a light laptop that is a remote control for a desktop full of containers, what eight pieces of work in parallel do to your head, and why neither an AGENTS.md nor "secure my app" is an answer.
