Running our own mail server, on purpose

James set up AgentSee's own mail server on a Swiss VPS, with an agent writing the OpenTofu and most of the configuration: two afternoons' work rather than the weeks it would once have taken. Abrar asks what was hard, and the answer is the click ops inside Stalwart's admin panel, a CLI that was not built for an agent, buttons the model insisted existed, and making the result reproducible afterwards with a snapshot script. They also cover borrowing sender reputation, the monitoring that is not built yet, whether either of them would recommend this to a client (no), and what it is like to let an agent drive the browser.
